# AskDB landing page

Static HTML, CSS and vanilla JavaScript, adapted from `idk.txt`. Open `index.html` directly, or run the existing Docker Compose app and visit `http://localhost:8000/landing/`. The API root also redirects here. Sign-in and Get Started links open the existing Streamlit app at port 8501 and select the corresponding account form.

The reference's exact CloudFront video and primary display-font stylesheet are used. Geist Pixel Circle is bundled as a local fallback. The existing AskDB vector logo is retained. Product copy and counters describe actual AskDB capabilities; unsupported enterprise endorsements and performance claims are omitted.

Navigation panels, mobile keyboard navigation, count-up values, background playback controls and reduced-motion behavior use no framework. Remote video and primary/UI font stylesheets require internet access; the local display font and black background remain available if they fail. The page retains the normal cursor.
